# エレキギター動画用デザイン素材

Codexの画像生成AIで制作した画像一式です。
動画テーマ：プロが解説！エレキギター最初の1本の選び方。

## ダウンロード

[画像一式のZIP](https://github.com/urajunco/skills-introduction-to-github/raw/refs/heads/assets/guitar-design-downloads/assets/guitar-designs/guitar_design_pack.zip)

GitHubで各PNGを開き、「Download raw file」から個別に保存できます。
ZIPはプレビュー非対応でも、同じボタンからダウンロードできます。

## 内容

- 01_thumbnail_headline.png：強い見出しのサムネイル
- 02_thumbnail_person_points.png：人物と要点のサムネイル（人物はAI生成の仮モデル）
- 03_thumbnail_comparison.png：比較のサムネイル
- 04_heading_3_designs.png：文字なしの見出し座布団3案（透過PNG）
- 05_telop_base_3_designs.png：文字なしのテロップベース3案（透過PNG）
- 06_telop_emphasis_3_designs.png：文字なしのテロップ装飾3案（透過PNG）
- 07_eyecatch_3_designs.png：アイキャッチ3案

サムネイルは各1672×941ピクセルです。その他は各3案を上・中・下に並べたシートです。
編集ソフトで必要な案を切り出して使用してください。
